## ⚠️ Requisitos de entorno

¡Importante! Este proyecto utiliza herramientas antiguas y puede presentar errores si se usan versiones modernas.

- ✅ Usa **Node.js `v14.21.3`** (no superior a `v14.x`)
- ❌ **No uses Node 16, 18 o 20**, ya que son incompatibles con `laravel-mix@^5.0.4`
- ✅ Instala dependencias usando `npm` (con el instalador oficial de Node.js)
- ❌ **No uses `pnpm` ni `yarn`**, ya que pueden generar conflictos con rutas internas y dependencias peer

Para desarrolladores con `nvm`: este proyecto incluye un archivo `.nvmrc` con la versión exacta recomendada.
